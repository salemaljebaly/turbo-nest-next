# Claude Instructions

Follow `AGENTS.md`. It is the canonical workflow for this repository.

Key reminders:

- Check branch and worktree before editing.
- Do not use `codex/` as a branch prefix.
- Use `AdminTable` for growing record lists.
- Use `AutocompleteSelect`/`EntitySelect` for related-record selectors.
- Use `todo:FeatureName` comments only for intentionally hidden or deferred
  features, and remove the comments when re-enabling the feature.
- Run the validation commands that match the change.
