# File Uploads

- Use the storage module presigned upload and confirm flow.
- Validate MIME type and size before issuing upload URLs.
- Persist upload metadata before returning a presigned URL.
- Confirm uploads before making files visible to application workflows.
- Keep object storage restore scripts generic and test restore drills.
