# UI Patterns

- Import primitives through `@/components/ui/*`.
- Use semantic theme tokens, not hard-coded product colors.
- Use `LoadingState`, `EmptyState`, and `ErrorState` for predictable page
  states.
- Keep dashboard UIs dense, scan-friendly, and workflow-first.
- Do not put cards inside cards.
